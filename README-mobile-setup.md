# MediaPipe Face Demo - 移动端访问指南

本指南将帮助你在手机上访问运行在Mac上的MediaPipe人脸识别demo。

## 前置条件

1. **Mac电脑**：运行macOS系统
2. **手机**：iOS或Android设备
3. **网络连接**：手机和Mac需要连接到同一个WiFi网络
4. **Node.js**：Mac上需要安装Node.js和npm

## 快速开始

### 方法一：使用自动化脚本（推荐）

1. **运行脚本**：
   ```bash
   ./start-mobile-server.sh
   ```

2. **按照提示操作**：
   - 脚本会自动检查依赖
   - 显示网络连接信息
   - 启动开发服务器
   - 提供手机访问地址

3. **在手机上访问**：
   - 打开手机浏览器
   - 访问脚本显示的HTTPS地址（通常是 `https://[Mac的IP]:3000`）
   - 如果提示证书不安全，点击"高级" -> "继续访问"

### 方法二：手动启动

1. **安装依赖**：
   ```bash
   npm install
   ```

2. **启动服务器**：
   ```bash
   npm run dev
   ```

3. **获取Mac的IP地址**：
   ```bash
   ifconfig | grep "inet " | grep -v 127.0.0.1
   ```

4. **在手机浏览器中访问**：
   ```
   https://[Mac的IP地址]:3000
   ```

## 详细步骤

### 1. 确保网络连接

确保手机和Mac连接到同一个WiFi网络：

- **手机热点**：在手机上开启热点，Mac连接到手机热点
- **WiFi路由器**：手机和Mac都连接到同一个WiFi网络
- **其他方式**：确保两台设备在同一局域网内

### 2. 获取Mac的IP地址

在Mac终端中运行：
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

找到类似 `192.168.1.100` 的IP地址。

### 3. 启动开发服务器

项目已配置为：
- 监听所有网络接口（`0.0.0.0`）
- 使用HTTPS协议（端口3000）
- 自动生成自签名证书

### 4. 手机访问

在手机浏览器中访问：
```
https://[Mac的IP地址]:3000
```

例如：`https://192.168.1.100:3000`

### 5. 处理证书警告

由于使用的是自签名证书，浏览器会显示安全警告：

**iOS Safari**：
1. 点击"高级"
2. 点击"访问此网站"
3. 选择"访问"

**Android Chrome**：
1. 点击"高级"
2. 点击"继续前往 [IP地址]（不安全）"

## 故障排除

### 问题1：无法获取IP地址
- 确保Mac已连接到网络
- 尝试重启网络连接

### 问题2：手机无法访问
- 检查防火墙设置
- 确保手机和Mac在同一网络
- 尝试ping Mac的IP地址

### 问题3：证书错误
- 这是正常现象，按照上述步骤处理证书警告
- 自签名证书在开发环境中是安全的

### 问题4：页面加载缓慢
- 检查网络连接质量
- 确保MediaPipe模型文件能正常下载

## 功能说明

在手机上访问后，你可以使用以下功能：

1. **人脸检测**：实时检测摄像头中的人脸
2. **特征点识别**：显示人脸关键点
3. **表情分析**：分析面部表情
4. **视频录制**：录制带有人脸识别效果的视频

## 技术细节

- **服务器**：Vite开发服务器
- **协议**：HTTPS（必需，因为MediaPipe需要安全上下文）
- **端口**：3000
- **跨域设置**：已配置CORS策略
- **证书**：自动生成的自签名证书

## 安全注意事项

1. 仅在可信任的网络环境中使用
2. 不要在生产环境中使用自签名证书
3. 定期更新依赖包以修复安全漏洞

## 支持

如果遇到问题，请检查：
1. Node.js版本是否兼容
2. 网络连接是否正常
3. 防火墙设置是否阻止了连接
4. 浏览器是否支持所需的Web API
