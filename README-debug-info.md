# 调试信息功能说明

## 概述

在界面中添加了一个专门的调试信息区块，用于实时显示人脸检测的详细信息。这个功能可以帮助开发者了解人脸检测的状态和参数。

## 功能特性

### 1. 实时调试信息显示
- **人脸区域坐标**: 显示检测到的人脸边界框坐标 (minX,minY - maxX,maxY)
- **人脸尺寸**: 显示人脸的宽度和高度（像素）
- **人脸位置**: 显示人脸左上角的X、Y坐标
- **检测状态**: 显示当前检测状态（成功/失败/错误信息）
- **关键点数量**: 显示检测到的面部关键点数量
- **眨眼状态**: 实时显示眨眼检测结果（睁眼/眨眼）
- **张嘴状态**: 实时显示张嘴检测结果（闭嘴/张嘴）

### 2. 界面控制
- **显示/隐藏切换**: 右上角的按钮可以控制调试信息的显示和隐藏
- **响应式设计**: 在移动端和桌面端都有良好的显示效果
- **半透明效果**: 隐藏时变为半透明，不影响主要界面

### 3. 样式设计
- **科技感外观**: 使用绿色主题，符合调试界面的风格
- **固定定位**: 位于页面左上角，不会影响主要功能区域
- **毛玻璃效果**: 使用backdrop-filter实现现代化的视觉效果

## 使用方法

### 1. 在主界面中
调试信息会在人脸检测过程中自动更新，无需额外操作。

### 2. 控制显示
- 点击调试信息区域右上角的"隐藏"按钮可以隐藏调试信息
- 点击"显示"按钮可以重新显示调试信息

### 3. 测试功能
可以使用 `test-debug.html` 页面来测试调试信息功能：
```bash
# 在浏览器中打开测试页面
open test-debug.html
```

## 调试信息说明

### 1. 人脸区域坐标
格式: `minX,minY - maxX,maxY`
- 表示检测到的人脸边界框的坐标范围
- 坐标基于视频流的像素坐标系

### 2. 人脸尺寸
- **宽度**: 人脸边界框的宽度（像素）
- **高度**: 人脸边界框的高度（像素）

### 3. 检测状态
- `检测成功`: 正常检测到人脸
- `❗️ 未检测到人脸`: 没有检测到人脸
- `❗️ 检测到多张人脸`: 检测到多个人脸
- `❌ 人脸核验初始化失败`: 模型初始化失败

### 4. 关键点数量
- 通常为468个关键点（MediaPipe标准）
- 表示检测到的面部特征点数量

### 5. 眨眼和张嘴状态
- **眨眼**: 检测到眨眼动作
- **睁眼**: 眼睛处于睁开状态
- **张嘴**: 检测到张嘴动作
- **闭嘴**: 嘴巴处于闭合状态

## 移动端适配

在移动设备上，调试信息区域会：
- 调整位置和大小以适应小屏幕
- 减小字体大小和间距
- 保持功能的完整性

## 注意事项

1. **性能影响**: 调试信息更新频率较高，在性能较差的设备上可能会影响流畅度
2. **隐私考虑**: 调试信息包含详细的人脸检测数据，在生产环境中建议隐藏
3. **浏览器兼容性**: 毛玻璃效果需要现代浏览器支持

## 未来改进

1. **可配置性**: 允许用户选择显示哪些调试信息
2. **数据导出**: 支持将调试数据导出为日志文件
