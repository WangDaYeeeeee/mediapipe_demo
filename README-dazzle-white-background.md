# 炫彩打光白色背景优化说明

## 问题描述

在炫彩打光过程中，由于页面背景是黑色，导致打光效率很低。黑色背景会吸收大部分光线，影响炫彩效果的视觉表现。同时，颜色序列需要按照正确的亮红色、亮绿色、亮红色的顺序进行。

## 解决方案

在炫彩打光过程中，每个颜色都叠加白色背景，以提升打光效率和视觉效果。通过颜色混合算法，确保每个炫彩颜色都有白色背景作为基础。

## 修改内容

### 1. 修改的文件
- `src/main.ts`: 修改 `captureDazzleFrames` 方法
- `test-dazzle.html`: 更新测试页面的 `dazzle` 方法

### 2. 核心逻辑

#### 在 `captureDazzleFrames` 方法中实现颜色混合：

```typescript
// 在炫彩打光过程中，每个颜色都叠加白色背景以提升打光效率
const whiteAlpha = 0.3; // 白色背景的透明度
const colorAlpha = a / 255;

// 计算白色背景和炫彩颜色的混合效果
const mixedR = Math.round(r * colorAlpha + 255 * whiteAlpha * (1 - colorAlpha));
const mixedG = Math.round(g * colorAlpha + 255 * whiteAlpha * (1 - colorAlpha));
const mixedB = Math.round(b * colorAlpha + 255 * whiteAlpha * (1 - colorAlpha));
const mixedA = colorAlpha + whiteAlpha * (1 - colorAlpha);

this.colorBackground.style.backgroundColor = `rgba(${mixedR}, ${mixedG}, ${mixedB}, ${mixedA})`;
```

#### 在炫彩打光结束后恢复背景状态：

```typescript
// 炫彩打光结束后，隐藏背景
this.colorBackground.style.opacity = '0';
```

### 3. 优化效果

1. **提升打光效率**: 每个炫彩颜色都叠加白色背景，能够更好地反射光线，增强炫彩效果的视觉表现
2. **改善用户体验**: 用户能够更清楚地看到炫彩打光的变化过程，颜色更加明亮
3. **保持原有功能**: 不影响原有的颜色序列和时序控制
4. **智能混合**: 通过颜色混合算法，确保每个颜色都有最佳的白色背景叠加效果

## 技术细节

### 时序控制
- 每个颜色都实时计算与白色背景的混合效果
- 炫彩打光结束后立即隐藏背景，恢复页面原始状态

### 颜色处理
- 白色背景透明度设置为0.3，提供适度的白色叠加效果
- 使用颜色混合算法计算每个炫彩颜色与白色背景的混合结果
- 颜色序列按照亮红色、亮绿色、亮红色的正确顺序
- 每个颜色间隔120ms的时序控制保持不变
