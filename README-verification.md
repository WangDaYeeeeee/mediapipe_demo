# 刷脸核验页面

基于 MediaPipe FaceLandmarker 开发的刷脸核验页面，支持移动端适配。

## 功能特性

### UI 设计
- ✅ 页面在一屏内展示完整，适配移动端
- ✅ 页面中心展示圆形的相机预览框
- ✅ 预览框上方为提示区，实时提醒用户动作
- ✅ 预览框下方为"开始"按钮和"终止"按钮
- ✅ 进度指示器显示当前核验步骤

### 核验流程
- ✅ 点击"开始"按钮，启动核验流程
- ✅ 要求用户正对摄像头，脸部在取景器保持居中
- ✅ 按顺序引导用户完成眨眼、张嘴这2个动作
- ✅ 在预览框外的背景进行炫彩打光2s（红、蓝、绿、黄）
- ✅ 上述流程通过后，获取一张用户的照片，确保睁眼

### 核验产物
- ✅ 在页面里展示最终获取到的照片
- ✅ 允许用户重新开始核验流程

## 使用方法

### 1. 启动开发服务器
```bash
npm run dev
```

### 2. 访问页面
- 原始人脸检测页面：`https://localhost:3001/`
- 刷脸核验页面：`https://localhost:3001/face-verification.html`

### 3. 核验步骤
1. **准备阶段**：将脸部对准圆形取景器中心
2. **眨眼检测**：按照提示眨眨眼
3. **张嘴检测**：按照提示张嘴
4. **炫彩打光**：背景会进行2秒的炫彩动画
5. **照片捕获**：自动获取一张睁眼的照片
6. **结果展示**：显示核验完成的照片

## 技术实现

### 核心技术
- **MediaPipe FaceLandmarker**：人脸特征点检测
- **TypeScript**：类型安全的JavaScript
- **Vite**：快速构建工具
- **Canvas API**：实时绘制人脸特征点

### 动作检测算法
- **脸部居中检测**：计算脸部轮廓中心点与画布中心的距离
- **眨眼检测**：监控眼睛高度变化，低于阈值时判定为眨眼
- **张嘴检测**：监控嘴唇高度变化，高于阈值时判定为张嘴

### 炫彩背景效果
- 使用CSS动画实现红、蓝、绿、黄的渐变背景
- 动画持续2秒，透明度从0到0.8再到0

## 开发说明

### 自定义核验步骤
可以在 `face-verification.ts` 中修改 `verificationSteps` 数组来自定义核验步骤：

```typescript
private verificationSteps: VerificationStep[] = [
  {
    name: 'position',
    tip: '请将脸部对准圆形取景器中心',
    condition: () => this.faceCentered,
    duration: 2000
  },
  // 添加更多步骤...
];
```

### 调整检测阈值
可以修改以下阈值来调整检测灵敏度：
- `blinkThreshold`：眨眼检测阈值（默认0.02）
- `mouthOpenThreshold`：张嘴检测阈值（默认0.05）
- 脸部居中距离阈值（默认50像素）

## 故障排除

### 常见问题
1. **摄像头无法启动**：检查浏览器权限设置
2. **模型加载失败**：检查网络连接
3. **检测不准确**：调整检测阈值或改善光线条件

### 调试模式
在浏览器控制台中可以看到详细的调试信息，包括：
- 模型加载状态
- 摄像头启动过程
- 动作检测结果
- 错误信息
